# contracts

Isinya `openapi/` (`common.yaml` untuk komponen bersama, `platform.yaml` untuk endpoint platform), `spectral.yaml` sebagai ruleset linter OpenAPI, serta `module.schema.json` sebagai JSON Schema manifest. Saat ini masih stub. Isinya diselesaikan pada PRD-000 FR-06 dan FR-23.
