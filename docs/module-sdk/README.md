# Module SDK

Folder ini akan berisi dokumentasi SDK modul: cara membuat modul baru, kontrak `sdk/module` dan `sdk/data`, manifest `module.json`, aturan versi modul, dan panduan frontend `@erp/module-sdk`. Isinya diisi pada M2, saat Module Registry dan developer tools sudah tersedia. Saat ini folder ini hanya berisi README ini.
