# M1 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun walking skeleton ERP: monorepo multi Go module yang ter-build menjadi satu binary `erp` (API + SPA ter-embed), terhubung ke PostgreSQL dengan migrasi platform, ter-instrumentasi OpenTelemetry, dengan seam tenancy dan aturan batas modul yang ditegakkan otomatis di CI.

**Architecture:** Root Go module (`github.com/rahmadmrhd/erp-go`) berisi platform (`internal/platform/*`), composition root (`internal/app`), dan CLI (`cmd/erp`). `sdk/` dan `modules/example/` adalah Go module terpisah yang disatukan `go.work`. HTTP memakai `net/http.ServeMux`; setiap route dibungkus middleware platform. Frontend di M1 hanya placeholder HTML yang dibundel Bun dan di-embed lewat `go:embed`.

**Tech Stack:** Go 1.27.2 · Bun 1.4.2 · PostgreSQL (major terbaru) · cobra · caarlos0/env v11 · joho/godotenv · GORM + `gorm.io/driver/postgres` (pgx v5) · goose v3 (Provider API) · OpenTelemetry Go SDK + otelhttp + `gorm.io/plugin/opentelemetry` · testcontainers-go · go-task v3 · golangci-lint v2 · Biome · dependency-cruiser · GitHub Actions

**Spec:** `docs/prd/PRD-000-inisialisasi-project.md` (milestone **M1**, §11), `docs/architecture/api-guidelines.md`, `docs/operations/deployment.md`

## Global Constraints

- Go module path root: `github.com/rahmadmrhd/erp-go`; SDK: `github.com/rahmadmrhd/erp-go/sdk`; modul: `github.com/rahmadmrhd/erp-go/modules/<name>`.
- Semua `go.mod` memakai `go 1.27` dan `toolchain go1.27.2` (seragam; diperiksa otomatis).
- Bun dikunci `1.4.2` (`packageManager: "bun@1.4.2"` dan `.bun-version`).
- Router: `net/http.ServeMux` stdlib saja. Library router pihak ketiga dilarang di `modules/**` dan `sdk/**` (D10).
- GORM hanya boleh diimpor oleh `modules/*/internal/infrastructure/**`, `internal/platform/database`, `internal/platform/modules/store`, `sdk/data` (D3b). `AutoMigrate` dilarang di kode non-test.
- Hanya `internal/platform/database` yang boleh mengimpor `gorm.io/driver/postgres` dan `github.com/jackc/pgx/v5/pgxpool` (FR-21: satu-satunya pembuka koneksi).
- Env: `ERP_DATABASE_URL` (wajib), `ERP_ENV` (`development|production`, default `production`), `ERP_HTTP_ADDR` (default `127.0.0.1:8080`), `ERP_LOG_FORMAT` (`json|text`, default `text` bila development, `json` bila production), `ERP_TENANCY_MODE` (hanya `single`), `ERP_DEFAULT_TENANT_ID` (UUID, opsional), `ERP_DB_SLOW_QUERY_MS` (default `200`). Variabel proses **menang** atas isi `--env-file`.
- Migrasi **tidak pernah** berjalan saat `serve` atau saat HTTP request; hanya lewat `erp migrate`.
- Respons API mengikuti api-guidelines: sukses `{"data": …}`, error `{"error": {"code","message","details","requestId","traceId"}}`, JSON camelCase.
- Header keamanan setiap respons: `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`.
- Setiap respons membawa `X-Request-Id` (diterima dari request bila cocok `^[A-Za-z0-9._-]{1,128}$`, selain itu dibuat UUIDv7).
- Cache: path `/assets/*` → `Cache-Control: public, max-age=31536000, immutable`; `index.html` dan `sw.js` → `Cache-Control: no-cache`.
- Graceful shutdown timeout: 25 detik (di bawah `TimeoutStopSec=30` systemd di deployment.md).
- Tanpa `OTEL_EXPORTER_OTLP_ENDPOINT` tidak boleh ada koneksi keluar (exporter no-op).
- Exit code CLI: `0` sukses, `1` error umum, `2` error validasi/konfigurasi.
- Taskfile: tidak memakai `rm`, `cp`, `sed`, atau utilitas khusus Unix; operasi file lewat fitur Taskfile atau program Go/Bun kecil.
- Commit message diakhiri `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **File env dengan CRLF dan/atau BOM UTF-8** (dibuat di Notepad Windows) → harus terbaca sama seperti file LF. Test di Task 5.
2. **Database tidak terjangkau** saat `serve` start → gagal cepat dengan pesan berisi host DB (tanpa password); DB mati setelah start → `/readyz` 503 sementara `/healthz` tetap 200. Test di Task 11.
3. **Path SPA aneh**: `/../../etc/passwd`, `/assets/%2e%2e/x`, dan route frontend bertitik seperti `/reports/2026.10` → traversal ditolak 404; route frontend (request `Accept: text/html`) tetap mendapat `index.html`. Test di Task 10.
4. **Dua `erp migrate up` bersamaan** (dua skrip deploy) → keduanya selesai tanpa error, migrasi diterapkan sekali, `default_tenant_id` hanya satu. Test di Task 8.
5. **Password DB berkarakter khusus** (`p@ss:w/rd%`) → `erp inspect config` dan semua pesan error menyamarkannya; DSN tetap terparse. Test di Task 5.
