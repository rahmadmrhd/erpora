# ADR-011: Kontrak UI extension dan design system

- **Status:** Proposed

## Konteks

Frontend modul di-co-locate di `modules/<name>/web` (ADR-001), dan komponen bersama berada di `packages/`. Kontrak antara app shell, modul, dan UI extension belum didefinisikan. Pada M1 `packages/ui-contracts` masih stub.

## Keputusan

Belum diputuskan. Keputusan ini akan dirumuskan saat frontend shell (M3) dan kontrak UI extension dikerjakan.
