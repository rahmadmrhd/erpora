# ADR-007: Semantik install, enable, disable, dan uninstall modul

- **Status:** Proposed

## Konteks

Modul dapat diaktifkan dan dinonaktifkan pada runtime tanpa rebuild binary (PRD-000 FR-19). Operasi ini menyentuh dependensi, migrasi modul, data, dan status yang terlihat oleh pengguna. Semantiknya belum didefinisikan secara formal.

## Keputusan

Belum diputuskan. Keputusan ini akan dirumuskan saat implementasi lifecycle modul (M2) dimulai.
